# DESBLOQUÉATE — proyecto Android inicial

Proyecto Android en Kotlin y Jetpack Compose.

## Requisitos para compilar
- JDK 17
- Android SDK 35
- Gradle 8.9 o compatible con Android Gradle Plugin 8.7.3

## Estado
Este es un prototipo inicial jugable de bloques. Todavía no es una versión comercial:
faltan gravedad automática, rotación, detección de fin de partida, pruebas, anuncios,
compras integradas, privacidad, firma de publicación y revisión de Google Play.

## Estructura
- `app/`: aplicación Android
- `app/src/main/java/com/desbloqueate/game/MainActivity.kt`: pantalla y lógica inicial
